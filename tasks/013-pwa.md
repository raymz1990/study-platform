# Task 013 — PWA (Progressive Web App)

**Fase:** 2 — MVP de Estudos | **Milestone:** 2 — MVP navegável
**Status:** Planejada | **Prioridade:** P1

---

## Objetivo

Transformar a aplicação em PWA instalável e funcional offline, com service worker, cache de conteúdo, manifest e atualização automática, usando vite-plugin-pwa.

## Contexto

O PWA deve oferecer: instalação, offline, cache e atualização automática (TECH_STACK.md §30). O conteúdo de estudo deve funcionar sem conexão (busca local, Markdown local). Artefatos oficiais de publicação incluem Manifest e Service Worker (DEPLOYMENT.md). Atualizações devem preservar histórico, progresso, favoritos e configurações (localStorage não é afetado por deploy).

- DEPLOYMENT.md (artefatos, atualizações, dados do usuário)

## Critérios de Aceite

- [ ] vite-plugin-pwa configurado com estratégia de cache adequada (precache do app shell; conteúdo Markdown em cache).
- [ ] Manifest completo: nome, ícones (192/512/maskable), tema, display standalone.
- [ ] Aplicação instalável em desktop e mobile.
- [ ] Funcionamento offline: navegação, conteúdo e busca disponíveis sem rede.
- [ ] Indicador visual de estado offline.
- [ ] Prompt de atualização quando nova versão disponível (atualização automática com consentimento).
- [ ] Dados do usuário (localStorage) preservados em atualizações.
- [ ] Lighthouse PWA: critérios de instalabilidade atendidos.

## Checklist de Testes

- [ ] Teste de build com service worker gerado.
- [ ] Teste manual: instalação em desktop e mobile.
- [ ] Teste manual: modo offline (navegação, leitura, busca).
- [ ] Teste de atualização: nova versão dispara prompt e preserva localStorage.
- [ ] Auditoria Lighthouse (PWA, performance, acessibilidade).

2. Ícones e manifest oficiais.
3. Componentes de update prompt e indicador offline.
4. Relatório Lighthouse anexado à PR.
