# Task 013 — Progressive Web App (PWA)

**Fase:** 2 — MVP de Estudos  
**Milestone:** 2 — MVP navegável  
**Status:** Planejada  
**Prioridade:** P1

---

# Objetivo

Transformar a plataforma em uma Progressive Web App (PWA) completa, permitindo instalação em desktop e dispositivos móveis, funcionamento offline, atualização controlada da aplicação e cache inteligente dos conteúdos oficiais.

O objetivo desta Task é preparar a aplicação para uso contínuo, inclusive sem conexão com a internet, preservando integralmente os dados locais do usuário.

---

# Contexto

Toda a aplicação foi desenvolvida para funcionar sem backend.

Todos os conteúdos são produzidos em build time e distribuídos juntamente com a aplicação.

O PWA deverá permitir que o usuário continue estudando mesmo sem conexão.

O cache deverá ser totalmente transparente ao usuário.

Toda a configuração deverá seguir:

- TECH_STACK.md
- SYSTEM_ARCHITECTURE.md
- DEPLOYMENT.md
- DATA_MODEL.md

# Escopo

## P0

### 1. Configuração do PWA

Configurar oficialmente o `vite-plugin-pwa`.

A configuração deverá gerar automaticamente:

- Manifest
- Service Worker
- Registro
- Estratégia de cache

---

### 2. Manifest

Gerar Manifest completo contendo:

- nome
- short_name
- descrição
- cores
- display standalone
- orientation
- theme_color
- background_color
- ícones oficiais

---

### 3. Instalação

A aplicação deverá ser instalável em:

- Chrome Desktop
- Edge
- Android
- iOS (quando suportado)

Não deverá existir nenhuma configuração manual.

---

### 4. Cache

Implementar estratégia de cache para:

- App Shell
- Assets
- Markdown
- JSON
- Índice de busca
- Fontes
- Ícones

Conteúdo oficial deverá permanecer disponível offline.

---

### 5. Funcionamento Offline

O usuário deverá conseguir:

- navegar
- estudar
- abrir capítulos
- pesquisar
- consultar roadmap
- visualizar progresso

sem conexão com a internet.

---

### 6. Atualizações

Quando uma nova versão estiver disponível:

- detectar automaticamente;
- informar ao usuário;
- permitir atualização controlada.

Nunca atualizar silenciosamente durante uma sessão de estudo.

---

### 7. Preservação dos Dados

Atualizações nunca poderão remover:

- progresso
- checklist
- configurações
- favoritos
- histórico

Todo o conteúdo persistido deverá permanecer no localStorage.

---

## P1

### Indicadores

Implementar componentes para:

- Offline
- Atualização disponível
- Atualizando aplicação

---

### Estratégia de Cache

Utilizar política adequada para cada recurso.

Exemplo:

- App Shell → precache
- Markdown → cache-first
- JSON → stale-while-revalidate
- Assets → cache-first

---

### Performance

Primeira instalação rápida.

Inicialização imediata após instalação.

# Fora do Escopo

- push notifications;
- background sync;
- login offline;
- múltiplos dispositivos;
- backend;
- analytics.
