# UI_UX_GUIDELINES.md

# Concurso AI Platform

## UI / UX Guidelines

Version: 1.0

---

# Objetivo

Este documento define todos os princípios de interface e experiência do usuário da plataforma.

O objetivo não é construir um site bonito.

O objetivo é construir a plataforma de estudos mais eficiente possível para preparação em concursos públicos.

Toda decisão de interface deve aumentar produtividade, retenção de conhecimento ou velocidade de estudo.

---

# Princípios

A plataforma deve priorizar:

- Clareza
- Rapidez
- Baixa carga cognitiva
- Navegação intuitiva
- Poucos cliques
- Consistência
- Acessibilidade

Nunca priorizar efeitos visuais em detrimento da usabilidade.

---

# Filosofia

A plataforma deve funcionar como um "cockpit" de estudos.

Ao abrir o sistema, o usuário deve saber imediatamente:

- O que estudar hoje
- Quanto tempo estudar
- O que revisar
- O que está atrasado
- Qual é sua evolução

Nunca exigir que o usuário decida por onde começar.

# Cores

Utilizar poucas cores.

As cores representam estado.

Exemplo:

Concluído

Amarelo

Atenção

# Tipografia

Máximo de duas famílias de fontes.

Textos confortáveis para leitura longa.

---

# Espaçamento

---

# Componentes

Cards iguais.

Nunca deixar o usuário sem feedback.

---

# Gamificação

Utilizar apenas elementos úteis.

Permitido:

Sequência de estudos

Dias consecutivos

Percentual concluído

Metas

Evitar:

Avatares

Moedas

Animações excessivas

Rankings artificiais

---

# Microinterações

Devem ser discretas.

Nunca atrasar o estudo.

---

# Performance

A interface deve responder imediatamente.

Tempo máximo de carregamento:

2 segundos.

Mudança entre páginas:

Instantânea.

---

# Conteúdo

Sempre privilegiar leitura.

Nunca utilizar blocos enormes de texto.

Utilizar:

Títulos

Listas

Quadros

Tabelas

Callouts

Diagramas

---

# Objetivo Final

A interface deve reduzir ao máximo a carga cognitiva do candidato, eliminar decisões desnecessárias e transformar cada sessão de estudo em um processo fluido, previsível e altamente eficiente, permitindo que o foco permaneça exclusivamente na aprendizagem e na resolução de questões.
