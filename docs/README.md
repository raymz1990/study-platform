# Concurso AI Platform

> Plataforma inteligente para preparação em concursos públicos, com foco em aprendizagem adaptativa, produção automatizada de conteúdo e integração com IA.

---

# Objetivo

A **Concurso AI Platform** é uma plataforma de estudos desenvolvida para apoiar candidatos em concursos públicos por meio de uma experiência de aprendizagem estruturada, reutilizável e orientada por inteligência artificial.

O projeto foi concebido para:

- transformar editais em planos de estudo executáveis;
- produzir conteúdo de alta qualidade;
- acompanhar a evolução do candidato;
- gerar materiais compatíveis com NotebookLM;
- criar podcasts de revisão;
- fornecer uma arquitetura reutilizável para diferentes concursos e bancas.

# Filosofia do Projeto

A plataforma foi construída seguindo cinco princípios fundamentais:

- Arquitetura modular.
- Código limpo e reutilizável.
- Conteúdo baseado no edital.
- Aprendizagem progressiva (do básico ao avançado).
- Evolução contínua da plataforma.

A prioridade é **aprovação no concurso**, e não apenas desenvolvimento de software.

# Regras Gerais

Sempre:

- consultar a documentação antes de implementar;
- preservar a arquitetura;
- reutilizar componentes existentes;
- manter documentação sincronizada;
- escrever código limpo;
- produzir conteúdo alinhado ao edital;
- seguir o padrão da banca ativa.

Nunca:

- alterar arquitetura sem justificativa;
- duplicar código;
- criar dependências desnecessárias;
- produzir conteúdo superficial;
- misturar estratégias de diferentes bancas.
