# Objetivo Pedagógico

O objetivo não é explicar um assunto.

O objetivo é preparar o candidato para acertar questões da banca.

Todo conteúdo deve responder:

"O que preciso saber para acertar esta questão na prova?"

---

# Público-alvo

Candidato adulto.

Conhecimento heterogêneo.

Pouca experiência em concursos.

Tempo limitado para estudar.

Busca eficiência.
